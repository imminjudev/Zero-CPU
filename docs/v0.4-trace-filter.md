# v0.4 Trace Search / Filter

This document describes the third Zero-CPU v0.4 debugger usability feature.

## Goal

Studio now has a simple trace filter.

The goal is to make the recorded trace easier to search while stepping through a
program.

## UI

New controls are added near the debugger command row:

```text
Trace Filter: [____________] [Apply Filter]
```

## How it works

The filter is case-insensitive.

When the filter is empty, `Recent Instruction Trace` behaves as before.

When the filter is set, `Recent Instruction Trace` only shows events whose
summary text contains the filter.

Useful filters:

```text
ADD
ALU_ADD
R1
STORE
MEMORY_WRITE
STACK_PUSH
CALL
RETURN
SOFTWARE_INTERRUPT
INT
DebugOutput
PC 656
```

## Filtered Fields

The first version matches against a combined text summary containing:

```text
instruction text
action
datapath string
ALU detail
Memory detail
Stack detail
Control Flow detail
compact TraceEvent string
error message
```

## Why this matters

v0.3 made each trace event much richer.

v0.4 needs navigation tools so that users can find important events.

Trace filtering helps answer:

```text
Where did R1 change?
Where did STACK_PUSH happen?
Where did control flow jump?
Where did MEMORY_WRITE happen?
Where did an error happen?
```

## Current Limitations

This is intentionally simple.

Known limitations:

```text
- filter is text-based
- no regex
- no structured filter language yet
- no filter export integration yet
- no highlight within the trace text yet
```

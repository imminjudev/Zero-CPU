# v0.4 Watch Expressions

This document describes the fourth Zero-CPU v0.4 debugger usability feature.

## Goal

Studio now includes a default Watch Expressions panel.

The goal is to make frequently inspected values visible in one place while
stepping through a program.

## First Version

This first version intentionally uses a fixed default watch set instead of a
custom expression parser.

The watched values include:

```text
PC
SP
Halted
Flags
R0
R1
R2
R3
R4
R7
Memory[180]
Memory[188]
Memory[196]
Memory[204]
Memory[212]
Memory[2048]
Memory[2056]
Memory[2064]
DebugOutput writes
DebugOutput ASCII
Timer tick
Timer interrupts
```

## Why these values?

The register watches cover common syscall/debugger state:

```text
R0
R1
R2
R3
R4
R7
```

The memory watches cover the debugger showcase data area:

```text
Memory[180]
Memory[188]
Memory[196]
Memory[204]
Memory[212]
```

The stack watches cover the default stack base region:

```text
Memory[2048]
Memory[2056]
Memory[2064]
```

The device watches cover the current MMIO demo devices:

```text
DebugOutputDevice
TimerDevice
```

## Why this matters

Before this patch, values were visible, but spread across:

```text
Register View
Memory View
System Panel
Execution Detail Probe
```

The Watch Expressions panel gives a compact repeated inspection area.

It helps answer:

```text
What values am I tracking while stepping?
Did R1/R2/R3 change?
Did the stack change?
Did the showcase memory slots update?
Did MMIO debug output happen?
Did timer state change?
```

## Current Limitations

This is intentionally a safe first watch implementation.

Known limitations:

```text
- watch expressions are fixed
- no editable watch list yet
- no Memory[address] parser yet
- no remove/add watch controls yet
- no change highlighting yet
```

These can be added later after the basic watch panel proves useful.

## Next Possible Improvements

```text
- editable watch list
- add/remove watch expression buttons
- Memory[addr] parser
- register name parser
- changed-since-last-step marker

```

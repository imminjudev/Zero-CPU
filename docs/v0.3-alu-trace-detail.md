# v0.3 ALU Trace Detail

This document describes the first Zero-CPU v0.3 debugger improvement.

## Goal

Studio v0.2 can already show that a register changed after an ALU instruction.

Example:

```text
R1: 30 -> 60
```

v0.3 begins by making the ALU operation itself more explicit.

The debugger can now display:

```text
ALU_ADD
lhs R1 = 30
rhs R1 = 30
result -> R1 = 60
```

## Added TraceEvent Data

`TraceEvent` now includes `ALUTraceDetail`.

The detail contains:

```text
active
operation
destination
lhs_text
rhs_text
lhs
rhs
result
has_lhs
has_rhs
has_result
note
```

## Supported Operations

The first version covers:

```text
ADD
SUB
MUL
DIV
CMP
TEST
AND
OR
XOR
NOT
```

For operations that write a destination register, the detail captures the result
from the post-instruction CPU state.

For `CMP` and `TEST`, the result is not written to a register, so the detail
records operands and notes that the result is reflected through flags.

## Studio Display

`Execution Detail Probe` now includes an operand snapshot for ALU operations.

Example:

```text
ALU Detail
  Active = true
  Operation = ALU_ADD
  Operand Snapshot
    lhs R1 = 30
    rhs R1 = 30
    result -> R1 = 60
  Register Result
    R1: 30 -> 60
  Flag Result = none
```

## Why this matters

This makes the debugger more useful for explaining CPU architecture.

The old view answered:

```text
What changed after this instruction?
```

The new view also answers:

```text
What values entered the ALU?
What operation did the ALU perform?
What result came out?
Where was it written?
```

## Current Limitations

This is an early v0.3 feature.

Limitations:

```text
- ALU detail is reconstructed from TraceEvent before/after snapshots.
- It is not yet emitted directly from the CPU execute path.
- Memory operands are best-effort snapshots from normal memory.
- MMIO read/write operands are not captured as explicit bus transactions yet.
```

This is acceptable for the first v0.3 patch because it avoids invasive changes
to the CPU execution core while improving Studio's explanatory power.
